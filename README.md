# Gold Planner 🪙

Gold Planner is a Google Apps Script-based application for gold investment management.

## Features

- Real-time gold price checking
- Antam gold saving target planner
- Gold buyback simulation
- Global gold price analysis
- Gold ownership history tracking

## Technology

- Google Apps Script
- HTML
- JavaScript
- Google Sheets Integration

## Files

- `Kode.gs` - Backend logic and data processing
- `Index.html` - User interface
- `appsscript.json` - Apps Script configuration
